# xunhen-front

This was the landing page for [xunhen](https://github.com/nuggocto/xunhen).
The site has been taken down and the xunhen.org domain is gone. The repository
stays as a graveyard for the old frontend code, and nothing here is maintained.

xunhen itself still works. You can install it with the install script, the AUR
package, or the Nix flake, and the commands are only in the
[xunhen README](https://github.com/nuggocto/xunhen#install).
